How it works

  1. You receive the download link from a staff member, or it is already on this page below.
  2. You open the file and read exactly what gets scanned.
  3. You press Accept or Decline. If you decline, nothing is scanned at all.
  4. You type your Discord ID when asked, so the owner knows the result is yours.
  5. The scan runs, shows you everything it found, and sends only the findings to the server owner.

What is not collected

  • No personal files. No documents, pictures or videos.
  • No browser data: no history, no cookies, no saved passwords.
  • No Discord tokens, no logins, no screenshots, no keystrokes.
  • No IP address, no hardware serial numbers, no username of your Windows account.

The only things sent are the names, file paths and SHA-256 hashes of files that match a known cheat or macro signature, plus your PC name and Windows version.

Why we do this

Cheats ruin matches for everyone. A scan that only looks for known cheat and macro software keeps our players safe and keeps this server fair. A clean result means nothing suspicious was found, not that you were accused of anything.
